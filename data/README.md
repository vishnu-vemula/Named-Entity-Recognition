# Dataset folder

This directory is intended for the benchmark CSV files required by the project:

- gossipcop_fake.csv
- gossipcop_real.csv
- politifact_fake.csv
- politifact_real.csv

Download or place these files here before running the training pipeline.

The project expects the files to be in the same folder as the training script is invoked from, or to be passed explicitly with `--data-dir`.
